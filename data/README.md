# Data boundary

No datasets are included or downloaded in the foundation. Future data acquisition
must record source URL, license, retrieval date, schema, target, units and limits.
50 Startups targets Profit; Boston Housing targets MEDV. Boston Housing requires
explicit review of historical provenance, the problematic racial variable and
ethical limitations before use; it is not a basis for current housing decisions.
Do not commit private/custom datasets. Data files are ignored by default; adding
an approved public teaching dataset requires an explicit tracked-file decision.
