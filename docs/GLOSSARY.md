# 中英術語表 / Glossary

以下例子為概念說明，非實驗結果。

| English | 繁體中文 | 定義 | 簡例 |
| --- | --- | --- | --- |
| Dataset | 資料集 | 用於分析的一組資料。 | 50 Startups 的公司資料表。 |
| Sample | 樣本 | 一筆觀測紀錄。 | 一家公司的一列資料。 |
| Feature X | 特徵 X | 供模型預測的輸入欄位或矩陣。 | 研發支出作為 X 的一欄。 |
| Target y | 目標 y | 要預測的輸出變數。 | Profit 是第一題的 y。 |
| Multiple Linear Regression | 多元線性迴歸 | 以多個特徵的線性組合估計連續目標。 | 以多種支出預測 Profit。 |
| CRISP-DM | 跨產業資料探勘標準流程 | 從商業理解至部署的六階段迭代流程。 | 先定義問題，再檢查資料。 |
| EDA | 探索式資料分析 | 以統計與視覺化理解資料。 | 檢查支出分布與缺失比例。 |
| Data Preparation | 資料準備 | 將原始資料轉成可建模的輸入。 | 在訓練資料內補缺值與編碼。 |
| Train/Test Split | 訓練／測試切分 | 分離用於學習和最後評估的資料。 | 固定亂數種子保留測試集。 |
| Data Leakage | 資料洩漏 | 訓練使用了預測時不應取得的資訊。 | 切分前用全資料平均值補缺值。 |
| One-Hot Encoding | 獨熱編碼 | 將類別轉成多個指示欄位。 | State 轉成各州的 0/1 欄。 |
| Cross-Validation | 交叉驗證 | 在訓練資料中輪替訓練與驗證分組。 | 以五折比較候選流程。 |
| Feature Selection | 特徵選擇 | 挑選用於建模的輸入欄位。 | 在訓練折內比較特徵子集。 |
| RFE | 遞迴特徵消除 | 反覆擬合並移除重要性較低的特徵。 | 每輪移除一個候選欄位。 |
| SFS | 循序特徵選擇 | 依驗證表現逐步加入或移除特徵。 | 前向選擇每次加入一欄。 |
| LassoCV | 交叉驗證 Lasso | 用交叉驗證選擇 L1 正則化強度的迴歸器。 | 部分係數可縮為零；需注意尺度。 |
| MAE | 平均絕對誤差 | 絕對預測誤差的平均；單位與 y 相同。 | 比較 Profit 預測的平均絕對偏差。 |
| MSE | 均方誤差 | 平方預測誤差的平均；單位為 y 的平方。 | 較大的誤差會被平方放大。 |
| RMSE | 均方根誤差 | MSE 的平方根；單位與 y 相同。 | 用 Profit 單位表達誤差。 |
| R² | 決定係數 | 1 減殘差平方和除以總平方和；可為負值。 | 負值可能表示比該評估集均值基準更差。 |
| Residual | 殘差 | 實際值減去預測值。 | 實際 100、預測 90，殘差為 10（示意）。 |
| Pipeline | 處理管線 | 串接前處理與估計器的可重複流程。 | 每個交叉驗證折內重新擬合編碼與迴歸。 |
| CSV URL | CSV 資料網址 | 指向逗號分隔資料的網路位址。 | 未來可由使用者提供；目前未實作。 |
| static website | 靜態網站 | 以 HTML/CSS/JS 檔案提供介面。 | 本專案 web/index.html。 |
| backend | 後端 | 在伺服器執行的應用服務。 | 可能由 Python 處理請求；目前未決議。 |
| ADR | 架構決策紀錄 | 保留決策背景、選項與後果的文件。 | ADR-0001 提議基礎架構。 |
| Holdout | 保留測試集 | 預先隔離、方法凍結後才評估的資料。 | 不用 test 分數選 k。 |
| Fold | 驗證折 | 交叉驗證的一次訓練／驗證分組。 | 五折輪替各一組作 validation。 |
| Pearson correlation | 皮爾森相關 | 衡量兩數值變數線性關係的係數，並不表示因果。 | 只在訓練資料內依 abs(r) 排序。 |
| F-test (f_regression) | 單變量迴歸 F 檢定 | 各特徵與連續目標線性關係的統計檢定，不是多特徵整體模型的評分。 | 在 training fold 計算 F 分數選欄位。 |
| Dummy baseline | 簡單參考基準 | 不使用特徵的比較對象。 | 用 training y 的均值作預測。 |
| Nested cross-validation | 巢狀交叉驗證 | 內層選方法／參數、外層評估整個選擇流程。 | 外層驗證資料不參與內層選 alpha。 |
