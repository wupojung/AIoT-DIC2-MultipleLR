# Architecture Decision Records

Use sequential ADR-NNNN-short-title.md filenames; never reuse a number.
Proposed means awaiting review; Accepted means the named owner approved it;
Superseded means a newer linked ADR replaces it. Preserve historical records.
The teacher/repository owner owns acceptance. Codex can author proposals, not
approve them. ADR-0001 is Accepted (owner approval recorded on 2026-10-16); see its record.
New evaluation and workflow specifications remain proposals pending their own review.

## Template
```markdown
# ADR-NNNN — Title
- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD
- Decision owner: name/role
- Related issue/PR: link
## Context
Evidence, constraints and unresolved questions.
## Decision
Specific proposal and scope.
## Alternatives
Options and reasons for choosing this proposal.
## Consequences
Benefits, costs, validation and follow-up work.
## Supersession
Link replacement ADR when applicable.
```
